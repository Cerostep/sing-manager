Nginx 完全配置指南

发布时间: 2026-04-13 作者: 技术博主 阅读时间: 12分钟

Nginx 介绍

Nginx 是一个高性能的 HTTP 和反向代理服务器，以其稳定性、高性能和低资源消耗而闻名。 与 Apache 相比，Nginx 使用更少的内存并能处理更多的并发连接。

Nginx 的优势

  • 高性能 - 能处理成千上万的并发连接
  • 低资源消耗 - 内存占用少
  • 高可靠性 - 主进程和工作进程分离
  • 模块化设计 - 易于扩展功能
  • 反向代理 - 可作为负载均衡器
  • 静态文件服务 - 高效的文件传输

Nginx 安装

在 Ubuntu/Debian 上安装 Nginx：

sudo apt-get update
sudo apt-get install nginx

# 启动 Nginx
sudo systemctl start nginx

# 设置开机自启
sudo systemctl enable nginx

# 检查运行状态
sudo systemctl status nginx

Nginx 目录结构

主要的 Nginx 目录和文件：

  • /etc/nginx/ - Nginx 配置目录
  • /etc/nginx/nginx.conf - 主配置文件
  • /etc/nginx/sites-available/ - 可用的站点配置
  • /etc/nginx/sites-enabled/ - 启用的站点配置
  • /var/log/nginx/ - 日志目录
  • /var/www/html/ - 默认网站根目录

基本配置

一个简单的静态网站配置：

server {
    listen 80;
    server_name example.com www.example.com;

    root /var/www/html;
    index index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }

    # 错误页面
    error_page 404 /404.html;
    error_page 500 502 503 504 /50x.html;
}

URL 重写和重定向

使用 rewrite 进行 URL 重写：

# 重定向 HTTP 到 HTTPS
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}

# 重写规则
location /old-page {
    rewrite ^/old-page/?$ /new-page permanent;
}

# 移除 .html 后缀
location / {
    try_files $uri $uri.html $uri/ =404;
}

反向代理配置

使用 Nginx 作为反向代理：

upstream backend {
    server 127.0.0.1:3000;
    server 127.0.0.1:3001;
    server 127.0.0.1:3002;
}

server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

负载均衡

Nginx 提供多种负载均衡策略：

# 轮询（默认）
upstream backend {
    server backend1.example.com;
    server backend2.example.com;
}

# 加权轮询
upstream backend {
    server backend1.example.com weight=2;
    server backend2.example.com weight=1;
}

# IP 哈希（会话保持）
upstream backend {
    ip_hash;
    server backend1.example.com;
    server backend2.example.com;
}

# 最少连接
upstream backend {
    least_conn;
    server backend1.example.com;
    server backend2.example.com;
}

SSL/TLS 配置

启用 HTTPS 和 SSL/TLS：

server {
    listen 443 ssl http2;
    server_name example.com;

    ssl_certificate /etc/ssl/certs/example.com.crt;
    ssl_certificate_key /etc/ssl/private/example.com.key;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # HSTS 头
    add_header Strict-Transport-Security "max-age=31536000" always;

    location / {
        root /var/www/html;
        index index.html;
    }
}

# 重定向 HTTP 到 HTTPS
server {
    listen 80;
    server_name example.com;
    return 301 https://$server_name$request_uri;
}

缓存配置

配置浏览器和代理缓存：

http {
    # 缓存路径
    proxy_cache_path /var/cache/nginx levels=1:2 keys_zone=my_cache:10m;

    server {
        location / {
            # 启用代理缓存
            proxy_cache my_cache;
            proxy_cache_valid 200 10m;
            proxy_cache_use_stale error timeout http_500 http_502 http_503 http_504;

            # 浏览器缓存
            expires 7d;
            add_header Cache-Control "public, max-age=604800";

            proxy_pass http://backend;
        }

        # 不缓存某些文件
        location ~ \.(php|jsp|asp)$ {
            proxy_pass http://backend;
            proxy_cache_use_stale off;
        }
    }
}

日志配置

log_format main '$remote_addr - $remote_user [$time_local] '
                 '"$request" $status $body_bytes_sent '
                 '"$http_referer" "$http_user_agent"';

server {
    access_log /var/log/nginx/access.log main;
    error_log /var/log/nginx/error.log warn;
}

性能优化

优化 Nginx 性能的配置：

worker_processes auto;  # 自动检测 CPU 核心数
worker_connections 4096;  # 每个工作进程的最大连接数

# 启用 Gzip 压缩
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript 
           application/json application/javascript application/xml+rss 
           application/rss+xml font/truetype font/opentype 
           application/vnd.ms-fontobject image/svg+xml;

常见错误和调试

检查配置语法：

sudo nginx -t

查看日志：

sudo tail -f /var/log/nginx/error.log
sudo tail -f /var/log/nginx/access.log

重要的 Nginx 命令

  • sudo systemctl start nginx - 启动
  • sudo systemctl stop nginx - 停止
  • sudo systemctl restart nginx - 重启
  • sudo systemctl reload nginx - 重新加载配置
  • sudo nginx -s reload - 轻量级重新加载
  • sudo nginx -t - 测试配置

最佳实践

  • 总是在更改配置前备份
  • 在生产环境前充分测试配置
  • 使用符号链接管理不同环境的配置
  • 定期检查和分析日志
  • 监控工作进程的资源使用
  • 实施安全头部和安全配置
  • 保持 Nginx 更新到最新版本

总结

Nginx 是现代互联网服务的重要组件。通过学习和掌握其配置， 你可以构建高性能、可靠和可扩展的 Web 基础设施。 本指南涵盖了最常见的使用场景，但 Nginx 的功能远不止这些， 官方文档是深入学习的最好资源。
