HTML 和 CSS 基础入门

发布时间: 2026-04-15 作者: 技术博主 阅读时间: 8分钟

介绍

HTML（超文本标记语言）和 CSS（层叠样式表）是现代web开发的基础。 HTML 提供网页的结构和内容，而 CSS 负责样式和布局。理解这两种技术是成为web开发者的第一步。

什么是 HTML？

HTML 是一种标记语言，使用标签（tag）来定义网页元素。每个标签告诉浏览器如何显示内容。 HTML 的设计遵循语义化原则，这意味着标签应该准确反映其内容的含义。

基本的 HTML 结构包括：

  • <!DOCTYPE html> - 文档类型声明
  • <html> - 根元素
  • <head> - 文档头部，包含元数据
  • <body> - 文档主体，包含可见内容

常用的 HTML 标签

以下是一些最常用的 HTML 标签：

  • <h1>...<h6> - 标题
  • <p> - 段落
  • <a> - 超链接
  • <div> - 通用容器
  • <span> - 行内容器
  • <img> - 图片
  • <ul> 和 <ol> - 列表
  • <form> - 表单

什么是 CSS？

CSS 用于控制 HTML 元素的外观和布局。它允许你改变颜色、字体、间距、大小等样式属性。 CSS 可以应用到多个元素，这样可以保持整个网站的一致性。

引入 CSS 的方式有三种：

  1. 内联样式 - 直接在 HTML 标签中使用 style 属性
  2. 内部样式 - 在 HTML 文档的 <style> 标签中定义
  3. 外部样式 - 在单独的 CSS 文件中定义（推荐）

CSS 选择器

CSS 选择器用于选择要样式化的 HTML 元素。主要的选择器类型包括：

/* 元素选择器 */
p {
    color: blue;
}

/* 类选择器 */
.highlight {
    background-color: yellow;
}

/* ID 选择器 */
#header {
    background-color: #333;
}

/* 属性选择器 */
input[type="text"] {
    border: 1px solid #ccc;
}

/* 伪类选择器 */
a:hover {
    color: red;
}

盒模型

理解 CSS 盒模型是掌握布局的关键。每个元素都被视为一个矩形盒子，由以下部分组成：

  • 内容 - 元素的实际内容
  • 内边距（Padding） - 内容周围的空间
  • 边框（Border） - 围绕内边距的线
  • 外边距（Margin） - 边框外的空间

布局方法

现代 CSS 提供了几种强大的布局方法：

  • 浮动（Float） - 传统的布局方法，现在较少使用
  • 定位（Positioning） - 相对定位、绝对定位等
  • Flexbox - 灵活的一维布局模式
  • Grid - 强大的二维布局系统

响应式设计基础

要使网站在各种设备上看起来好看，需要使用媒体查询和流动布局： 

/* 移动优先的响应式设计 */
.container {
    width: 100%;
}

/* 平板设备 */
@media (min-width: 768px) {
    .container {
        width: 90%;
        margin: 0 auto;
    }
}

/* 桌面设备 */
@media (min-width: 1024px) {
    .container {
        width: 80%;
        max-width: 1200px;
    }
}

最佳实践

  • 使用语义化的 HTML 标签
  • 将样式与结构分离（使用外部 CSS 文件）
  • 使用有意义的类名和 ID 名称
  • 遵循 DRY 原则（Don't Repeat Yourself）
  • 测试跨浏览器兼容性
  • 优先考虑可访问性（Accessibility）
  • 使用版本控制系统管理代码

总结

HTML 和 CSS 是 web 开发的基石。掌握这两种技术将为你的编程生涯奠定坚实的基础。 通过不断的练习和学习，你将能够创建美观、易用且高效的网站。记住，优秀的 web 开发者 不仅要写出功能正确的代码，还要确保代码易于维护和扩展。

下一步

现在你已经了解了 HTML 和 CSS 的基础，下一步可以：

  1. 练习创建简单的网页
  2. 学习 JavaScript 来添加交互功能
  3. 探索更高级的 CSS 特性
  4. 学习如何使用开发者工具进行调试
